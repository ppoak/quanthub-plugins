# 因子数据身份

`identity.json` 记录计算定义和历史数据摘要，供验证、评估和更新核对输入。数值正确性由独立验证确认。

增量计算追加日期分区后更新身份记录。历史分区改写时，须重算完整已存区间。

## 查看数据身份

`identity.json` 保存在因子数据目录，与日期分区同级：

| 字段 | 含义 |
| --- | --- |
| `factor_name` | 数据所属的因子包 |
| `columns` | 数据包含的因子列 |
| `fingerprint` | `main.py` 及其递归计算依赖的 SHA-256 指纹 |
| `manifest` | 历史起止日期与整体摘要 |

`manifest` 保存 `begin`、`end` 和 `sha256`。摘要按相对路径排序，覆盖全部历史分区文件的相对路径、纳秒级修改时间和内容。

## 查看验证和评估记录

每列的运行记录保存在列级产物目录的 `config.json`：

- `factor`：因子包、因子列和计算代码指纹；使用独立存储名时记录 `dataset`。
- `validation`：请求验证的起止日期、容差、数据摘要、完成时间及结果。
- `evaluation`：评估使用的日期、参数、资源及结果。

验证和评估记录输入截止日期与摘要，后续脚本据此核验结果。实际复算的日期、股票和误差从 `audit.csv` 读取。

查看结论读因子 README；追查验证差异读 `audit.csv`，查看 IC、收益、换手和相关性读对应指标 CSV。

## 遇到不匹配时

先核对因子包和数据目录是否选对，再处理原因：

- 身份缺失或历史摘要变化：通过 Calculate 重算完整已存区间。
- 计算代码变化：按当前定义重算完整历史。
- 输出列不足：核对本次需要的列，需要补算时按因子包重新计算。

需要编写核验代码时，使用 [Factor Protocol 数据身份接口](../src/factor_protocol/identity.py)。
