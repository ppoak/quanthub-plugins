# 策略框架运行模型

## 组件

| 组件 | 核心职责 |
|---|---|
| `Strategy` | 根据输入数据形成交易意图 |
| `Client` | 提供买入、卖出和撤单接口 |
| `Exchange` | 管理已接受订单，并产生订单状态与成交事实 |
| `Account` | 保存初始资金、当前现金和持仓状态 |
| `Ledger` | 记录终态订单和已确认成交，供后续回放 |
| `Store` | 汇集并去重订单、成交事实，提供导出能力 |
| `Evaluator` | 根据成交事实、价格序列和初始状态计算净值与绩效指标 |

`Order` 是交易意图，`Execution` 是成交事实，`Position` 是当前持仓状态。策略经 `Client` 发起交易；订单进入 `Exchange` 管理；确认成交后，账户状态同步更新，事实写入 `Ledger` 并汇集到 `Store`。评估器可从成交与价格数据重建持仓和净值。

## 事实与评估

`BaseLedger` 和 `Store` 都按订单或成交标识去重。账本保留终态订单与已确认成交；`Store` 适用于汇集、导出订单和成交集合。净值、持仓、市值和交易统计可从成交事实复算。

价格矩阵以 bar 时间为索引、证券代码为列；成交时间对齐至其时间戳之前最近的 bar。`evaluate_executions` 返回包含期初资金、期末净值、收益、回撤、波动和交易统计的指标序列。
